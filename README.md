💌 Web Thiệp Chat Chúc Mừng 20/10
Ứng dụng nhắn tin gửi lời chúc 20/10 dễ thương dành tặng chị em phụ nữ trực quan ngay trên trình duyệt!

🛠️ Hướng Dẫn Tùy Chỉnh Nhanh
Bạn có thể mở file ``` index.html ``` và chỉnh sửa các mục sau theo ý thích:

1. Thay đổi tên tiêu đề khung chat
Tìm đến dòng có chứa class ```chat-header ```:

``` <div class="chat-header">🌸 Anh Chàng Ẩn Danh 🌸</div> ```
Đổi chữ Anh Chàng Ẩn Danh thành tên của bạn.

2. Thay đổi lời chúc tự động
Tìm đến mảng ```defaultResponses``` ở cuối file:
```
const defaultResponses = 
    "Chúc bạn ngày 20/10 ngập tràn niềm vui, xinh đẹp và luôn hạnh phúc nhé! 💖",
    "Mong rằng mỗi ngày của bạn đều rạng rỡ như những bông hoa! 💐"
; 
```
Thêm hoặc sửa nội dung bên trong dấu ngoặc kép "".

🚀 Cách Bật Website Trực Tuyến
1 Vào mục Settings của repository trên GitHub.

2 Chọn Pages ở thanh menu bên trái.

3 Ở phần Build and deployment -> Branch, chọn main (hoặc master) rồi bấm Save.

4 Chờ khoảng 1 phút và nhận đường link website trực tuyến để gửi tặng mọi người!
